## Veelgestelde vragen

### Super, dank je! Hebben jullie ook vegetarische gerechten op het menu?
Ja zeker! We hebben meerdere vegetarische opties op het menu. Vraag gerust naar ons dagelijkse vegetarische aanbod — we helpen je graag kiezen.

### Mooi! Is het terras vandaag open?
Ja, bij mooi weer is ons terras open. Kom gerust langs — we reserveren ook graag een tafel voor je.

### Kunnen we ook afhalen of laten bezorgen?
Afhalen kan meestal wel — bestel ongeveer 30 minuten van tevoren. Bezorgen hangt af van je locatie; stuur je adres door, dan kijken we wat mogelijk is.
